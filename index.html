Kanana Mail Studio

학생 기본 정보와 상황 설명을 바탕으로 교수님께 보낼 정중한 메일 초안을 생성합니다.

브라우저 직접 호출 API 키는 입력 시점에만 사용하며 페이지 안에 하드코딩하지 않습니다.

입력

교수님 정보, 학생 정보, 요청 상황을 채우면 바로 초안을 만들 수 있습니다.

API 키와 생성 결과는 저장하지 않습니다.

출력

생성된 제목과 본문을 바로 복사해 메일에 붙여넣을 수 있습니다.

아직 생성 전입니다.
